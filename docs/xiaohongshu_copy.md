## 正文

前段时间在 Linux 上读论文，碰到不熟的句子还是得复制、切浏览器、粘贴，再切回来。

单看一次没什么，一下午来几十次就很烦，注意力全浪费在切窗口上了。

所以我干脆自己写了一个划词助手，叫 Selection-Assistance。

现在的用法很简单：选中文字，按 `Ctrl + Shift + D` 翻译，按 `Ctrl + Shift + E` 解释。结果直接出现在鼠标旁边，不用离开正在看的页面。

翻译完还可以在下面接着问。比如遇到一个词，我通常会继续问一句“放在这段话里是什么意思”或者“给个更自然的例句”。它会保留前面的内容，不用重新交代一遍。

单词会带音标，论文里的公式可以正常显示，代码块也不会挤成一团。需要时还能打开 DeepSeek 的思考模式，不过我平时更喜欢关着，出来得快一点。

最近又把界面和流式输出重做了一遍。之前模型输出快的时候，文字会一顿一顿地跳；现在顺了很多。往上翻旧消息时，页面也不会硬把我拽回最下面。

还有一个很小但很烦的问题也修了：没有选中文字时按快捷键，不会再拿上一次剪贴板里的内容去翻译。如果前面已经聊过，它只会把原来的窗口叫回来，方便接着问。

目前我主要在 Linux X11 上用，VSCode、Chrome、PDF 阅读器和 Zotero 这些场景都覆盖到了。Wayland 对模拟复制限制比较多，所以暂时不能保证体验，这点先说在前面。

项目已经开源，README 里写了安装步骤：

https://github.com/xuyicheng-zju/Selection-Assistance

它还不是装完就什么都不用管的商业软件，需要自己配一下百炼 API Key 和 `xdotool`。如果你也经常在 Linux 上读论文或英文文档，可以试试看。有问题直接提 Issue，我也想看看不同桌面环境下还有哪些坑。

## 置顶评论

补充一下实现：前端是 Electron + React，后端是 FastAPI，文本模型用 DeepSeek，OCR / 看图接口用 Qwen-VL。目前主要适配 X11；安装需要 Node.js 20+、Python 3.11+、`uv`、`xdotool` 和一个阿里云百炼 API Key。命令都在 GitHub README 里。
